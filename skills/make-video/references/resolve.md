# Resolve and editor automation

Inspect installed version/edition, local scripting documentation, current project, and active timeline before mutation. A read-only connection and tiny timeline/export establish capabilities; current online features do not prove support in an older installation.

Use supported scripts/imports for frame-exact assembly. If external scripting is unavailable, the native Lua console may expose `resolve` or `fusion:GetResolve()`; verify locally. GUI operation is valid for supported controls. Use the available computer-use tool's fresh accessibility snapshot and verified app window. Background hotkeys, stale tokens, and blind coordinates are fragile; inspect state after meaningful changes.

## Assembly pitfalls

- Translate frame conventions explicitly. An N-frame half-open manifest range can require an inclusive API end of start+N-1.
- Verify frame rate, total duration, media count, and contiguous positions after import. XML sample characteristics may declare dimensions at several levels; update all relevant fields for UHD.
- Register LUTs in the installed editor's expected directory, refresh the LUT list, apply to the intended node, and read back results. Preserve LUTs with the project.
- Verify imported stereo routing/gain. If XML duplicates channels/tracks, isolate imported audio on the new timeline and insert one explicit stereo source. Preserve unrelated tracks.
- When title automation is unsupported, a validated alpha overlay such as ProRes 4444 can be more reliable than an unverified Fusion graph. Check alpha, color interpretation, duration, and rendered text.
- Verify color management through an exported sample after importing timelines or changing projects. Global settings can affect other timelines.

## Save, render, resume

Save named projects/timelines and a native backup when useful or requested. A project backup may omit media, LUTs, fonts, and overlays; list dependencies and verify relinking.

Before render, record project/timeline identity, destination, expected frame count, settings, and job ID. After timeout, inspect that job/file rather than creating another. Existing files are complete only after validation. Persist stage receipts for resumed work.

Separate native high-quality picture export from audio mux/final encoding when it is the reliable supported path. Preserve the master. Close normally when requested, after saving and verifying delivery. Verify process/window closure rather than treating a quit keystroke as proof; avoid force-killing unsaved work.
